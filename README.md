# 📊 COVID-19 Global Analysis Dashboard

This project presents an interactive COVID-19 data analysis dashboard built using Power BI.

---

## 🔍 Overview
This dashboard analyzes COVID-19 trends across multiple countries, focusing on:
- Total cases, deaths, and recoveries
- Vaccination rates
- Time-based trends

---

## 🛠️ Tools Used
- Power BI  
- Excel  

---

## 📈 Key Insights
- COVID-19 cases show clear peaks and declines over time  
- Recovery rates are significantly higher compared to death rates  
- Vaccination rates vary across different countries
